# CMOS Comparator Design Using Cadence Virtuoso

## Overview
This project focuses on the design and simulation of a CMOS comparator using Cadence Virtuoso. A comparator is an analog circuit that compares two input voltages and produces an output based on their relative magnitudes.

## Objectives
- Understand the working principle of a CMOS comparator.
- Design the circuit at the transistor level.
- Implement the schematic using Cadence Virtuoso.
- Perform simulations to verify circuit functionality.

## Tools & Technologies
- Cadence Virtuoso
- CMOS Technology
- MOSFET
- Analog Circuit Design

## Project Files
- `Schematic/` – Comparator circuit schematic.
- `Simulation/` – Simulation results and waveforms.
- `Layout/` – Physical layout (if available).

## Working Principle
The comparator compares two input voltages (Vin+ and Vin−). When Vin+ is greater than Vin−, the output switches to one logic state. When Vin+ is less than Vin−, the output switches to the opposite state.

## Applications
- Analog-to-digital converters (ADCs)
- Voltage detection
